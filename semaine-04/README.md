# Semaine 4 — Qualité du code et inversion des dépendances

Cette semaine poursuit le projet de restaurant avec des réusinages courts. Les
trois exercices utilisent la même solution cumulative.

| Étape | Activité |
|---|---|
| [Exercice 1](./E01-substitution-dip.md) | Substituer une dépendance concrète et appliquer DI/DIP |
| [Exercice 2](./E02-srp-cqs.md) | Séparer les responsabilités et distinguer commandes et requêtes |
| [Exercice 3](./E03-loi-demeter.md) | Réduire une chaîne d'appels avec la loi de Déméter |

Le départ compilable se trouve dans
[`S04E01E03_Restaurant_Qualite`](./S04E01E03_Restaurant_Qualite/).

Chaque exercice se réalise dans une branche `fonctionnalite/...` créée depuis
`dev`. Revoyez les commandes de la semaine 3 au besoin. Avant chaque fusion,
exécutez les tests et vérifiez la branche active avec `git status`.
